# Sample Data

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

본 샘플 데이터는 기능 시연을 위한 합성 데이터입니다. 실제 회원, 고객, 환자, 트레이너의 개인정보 또는 건강정보를 포함하지 않습니다.

## 사용 원칙

- 실제 회원 이름, 연락처, 사진, 영상, 건강정보를 포함하지 않습니다.
- 실제 회원 데이터를 일부 변형한 자료도 샘플에 넣지 않습니다.
- 제품 시연, 내부 검토, 개발 테스트 목적에 한해 사용합니다.
- 실제 회원 정보와 결합하거나 재식별을 시도하지 않습니다.
