# 파일럿 리스크 체크리스트

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

## 1. 의료 오인 리스크

- 화면과 리포트에 비의료 안전 문구가 보이는가?
- BLOCK이 의료 주의 필요 상태처럼 보이지 않는가?
- 통증 관련 문구가 원인 확정처럼 보이지 않는가?

## 2. 개인정보 리스크

- 실제 데이터 수집 전 동의서가 있는가?
- 촬영 이미지 저장 여부를 회원에게 설명했는가?
- 삭제 요청 절차가 있는가?

## 3. 운영 리스크

- 트레이너가 리포트를 검토하는 시간이 과도하지 않은가?
- 세션 입력 항목이 너무 많지 않은가?
- 센터 대표가 비용 대비 효과를 이해하는가?

## 4. 기술 리스크

- `python manage.py check`가 통과하는가?
- `python manage.py test`가 통과하는가?
- 테스트 계정과 합성 데이터만 사용 중인가?
