# 비의료 서비스 경계 정책

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

LIGHT ONE V2는 PT 현장의 상담 기록과 운동 수행 데이터를 구조화하는 비의료 운동상담 지원 서비스입니다. 제품은 의료기기, 진단 도구, 치료 프로그램, 처방 소프트웨어가 아닙니다.

## 1. 제공하는 것

- 운동 기록, RPE, 통증 반응 참고값, 트레이너 메모 구조화
- QS/JATC 등 상담 참고 지표 산출
- AUTO / REVIEW / BLOCK 라우팅을 통한 트레이너 검토 우선순위 표시
- 회원에게 설명 가능한 비의료 상담 리포트 초안
- 촬영 조건과 입력 품질을 확인하는 보조 QC 정보

## 2. 제공하지 않는 것

- 질병, 손상, 자세 이상에 대한 의료 진단
- 통증 원인 확정
- 치료, 재활 치료, 의학적 처방
- 임상 의사결정 지원
- AI 단독 판단에 따른 운동 계획 확정
- 임상 효과 주장, 질병 예방, 임상 개선 효과 주장

## 3. 표현 가이드

금지 또는 주의 표현은 안전한 표현으로 바꿔야 합니다.

- 진단 → 확인, 기록, 상담 참고
- 치료 → 관리, 컨디셔닝, 운동상담
- 처방 → 운동 제안, 프로그램 조정 제안
- 회원/고객 → 회원, 고객
- 통증 진단 → 통증 반응 참고
- 주의 필요 상태 → 주의 필요 상태
- 운동 중단 → 트레이너 검토 전 진행 보류
- 비의료 운동상담 참고 분석 → 비의료 운동상담 참고 분석

## 4. 라우팅 문구 기준

`AUTO`는 상담 리포트 초안 생성 가능 상태입니다. 트레이너 최종 확인 후 전달합니다.

`REVIEW`는 통증 반응 참고값 또는 품질 경계값이 있어 트레이너 확인이 필요한 상태입니다.

`BLOCK`은 의료 판단이 아닙니다. 트레이너 검토 전 진행 보류 상태입니다.

## 5. 화면·보고서 검수 체크

- “진단”, “치료”, “처방”, “완치”, “질병”, “회원/고객” 표현이 긍정 주장으로 쓰이지 않았는가?
- 통증 관련 문구가 “원인 확정”이 아니라 “반응 참고”로 표현되는가?
- AI 또는 시스템이 최종 판단자가 아니라 트레이너 검토 보조 도구로 설명되는가?
- BLOCK 상태가 의료 판단처럼 보이지 않는가?
- 모든 화면에 비의료 안전 문구가 노출되는가?
