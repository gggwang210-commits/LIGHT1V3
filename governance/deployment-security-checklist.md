# 배포 보안 체크리스트

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

이 문서는 Django MVP를 운영 또는 파일럿 환경에 올리기 전 확인해야 할 최소 보안 기준입니다.

## 1. 환경변수

- `SECRET_KEY`는 운영 환경변수로 주입합니다.
- `DEBUG=False`를 적용합니다.
- `ALLOWED_HOSTS`는 실제 도메인만 허용합니다.
- `.env`는 저장소와 ZIP에 포함하지 않습니다.
- `.env.example`에는 실제 비밀값을 넣지 않습니다.

## 2. HTTPS와 쿠키

- 운영 환경은 HTTPS를 사용합니다.
- `SESSION_COOKIE_SECURE=True`를 적용합니다.
- `CSRF_COOKIE_SECURE=True`를 적용합니다.
- HSTS 적용 여부를 배포 환경에 맞게 결정합니다.

## 3. 데이터베이스

- 로컬 `db.sqlite3`는 최종 ZIP에 포함하지 않습니다.
- 운영 DB 계정은 최소 권한 원칙을 적용합니다.
- 백업 보관 기간과 삭제 기준을 문서화합니다.

## 4. 정적·미디어 파일

- 실제 회원 촬영 이미지와 원본 영상은 저장소에 포함하지 않습니다.
- 파일럿 미디어는 접근 권한이 통제된 별도 스토리지에 보관합니다.
- 대용량 원본 영상은 최종 ZIP에 포함하지 않습니다.

## 5. [확인필요]

[확인필요] 운영 배포 전 보안 전문가 또는 배포 담당자가 환경변수, HTTPS, DB, 로그 설정을 최종 확인해야 합니다.
