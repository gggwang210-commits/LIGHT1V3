# 개인정보·합성 데이터 체크리스트

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

LIGHT ONE V2는 파일럿 전까지 합성 데이터 사용을 원칙으로 합니다. 실제 회원 데이터, 촬영 이미지, 통증 반응 기록을 수집하려면 동의, 보관, 삭제, 접근 권한 기준을 먼저 정해야 합니다.

## 1. 저장소 포함 금지

- 실제 이름
- 전화번호
- 이메일
- 주소
- 생년월일
- 건강정보
- 촬영 이미지
- 계좌번호
- API 키
- 토큰
- 비밀번호
- 내부 시스템 URL
- `db.sqlite3`
- `.env`

## 2. 합성 데이터 기준

샘플 데이터는 기능 시연을 위한 합성 데이터로만 사용합니다. 실제 회원의 운동 기록이나 통증 반응을 변형한 데이터도 원칙적으로 샘플에 넣지 않습니다.

## 3. 파일럿 전 필수 준비

- 수집 항목 목록 작성
- 수집 목적 작성
- 보관 기간 작성
- 삭제 요청 절차 작성
- 접근 권한자 지정
- 외부 공유 전 비식별화 기준 수립
- 촬영 이미지 저장 여부 결정
- 파일럿 종료 후 데이터 삭제 또는 보관 기준 결정

## 4. 운영 로그 기준

오류 로그, 관리자 알림, 분석 로그에는 이름, 연락처, 건강정보가 원문으로 남지 않도록 합니다.
