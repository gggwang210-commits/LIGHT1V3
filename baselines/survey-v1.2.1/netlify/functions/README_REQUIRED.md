# 운영에 필요한 Netlify Function 원본

이 검토용 ZIP에는 서버 함수 실행 코드를 넣지 않았습니다. 운영 배포에는 다음 검증된 원본이 필요합니다.

- `submit-survey.js`
- `admin-summary.js`
- `send-report.js`
- `_lib/report.js`

추정 구현을 새로 만들지 말고, LIGHT ONE 설문 v1.2.1과 함께 운영하던 원본을 사용하세요. 적용 전에 아래를 확인합니다.

- 설문 역할 `owner`, `trainer`, `member`와 문항 허용 목록
- 회원 연령 조건과 연락 동의 분리
- 연락 미동의 시 연락정보 제거
- 응답 ID 기반 중복 처리의 기존 의미
- 관리자 `X-Admin-Password` 인증
- 집계 기간 `7d`, `30d`, `90d`, `all`
- 테스트·분석 제외 응답과 역할별 선택률 계산
- 관리자 응답과 이메일에 개인 응답자 정보 미포함
- 인증 실패, 저장 실패, 외부 API 실패 로그의 비밀값 마스킹

함수 원본과 환경변수 없이는 실제 저장·집계·이메일을 검증할 수 없습니다.
