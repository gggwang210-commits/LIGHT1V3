# 대시보드 제품 명세

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

## 1. 목적

대시보드는 트레이너가 회원 세션 기록, QS/JATC 참고값, 통증 반응 참고값, 촬영 QC 상태를 한 화면에서 확인하도록 돕습니다.

## 2. 주요 영역

- Hero: 비의료 PT 상담 리포트 SaaS 포지셔닝
- 진행 현황: 전체 세션, AUTO, REVIEW, BLOCK
- 차트: QS 흐름과 참고 지표 분포
- 리포트 목록: 최근 회원 세션
- 우선순위: 파일럿과 사업 실행 항목

## 3. 라우팅 표시

`AUTO`는 초안 생성 가능 상태입니다.

`REVIEW`는 트레이너 확인 필요 상태입니다.

`BLOCK`은 트레이너 검토 전 진행 보류 상태입니다.

## 4. UX 기준

- 모든 화면 상단 또는 하단에 비의료 안전 문구를 노출합니다.
- 점수는 판단 결과가 아니라 상담 참고값으로 설명합니다.
- 회원에게 보이는 문구는 불안감을 조장하지 않습니다.
- Chart.js CDN이 실패해도 표와 카드로 핵심 정보를 확인할 수 있어야 합니다.
