# 파일럿 준비 체크리스트

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

## 1. 파일럿 목표

1곳의 PT샵 또는 필라테스 센터에서 리포트 입력 시간, 설명 가능성, 재상담 활용 가능성을 확인합니다.

## 2. 준비물

- 테스트 계정
- 합성 데이터
- 샘플 리포트
- 트레이너 인터뷰 질문지
- 개인정보 동의서 초안
- 비의료 안내 문구

## 3. 측정 지표

- 세션 입력 시간
- 리포트 이해도
- 트레이너 수정 필요 항목 수
- 상담 준비 시간 단축 체감
- 월 구독 지불의사
- 실제 운영 부담

## 4. 진행 순서

1. 합성 데이터로 데모를 시연합니다.
2. 트레이너가 직접 세션 입력을 해봅니다.
3. 샘플 리포트를 회원 설명 상황으로 검토합니다.
4. 불필요한 입력 항목과 위험 문구를 제거합니다.
5. 가격 지불의사를 확인합니다.

## 5. 파일럿 종료 후 판단

파일럿 후에는 상용화가 아니라 다음 3가지를 먼저 판단합니다.

- 고객 문제가 실제로 반복되는가?
- 트레이너가 입력 시간을 감수할 만큼 리포트를 가치 있게 보는가?
- 센터 대표가 월 구독 비용을 낼 이유가 있는가?
