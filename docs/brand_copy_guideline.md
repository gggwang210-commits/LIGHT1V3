# LIGHT ONE Brand Copy Guideline

## Canonical copy

LIGHT ONE의 페이지 단위 제목과 핵심 브랜드 메시지는 아래 문구를 기준으로 한다.

1. Primary title: LIGHT ONE PT V1 REPORT SYSTEM
2. Service line: 트레이너 회원관리 SaaS 서비스
3. Positioning line: AI 기반 비의료적 컨디셔닝 케어

## Usage

- 로그인, 메인 대시보드, 트레이너 콘솔, 발표 자료의 첫 제목은 Primary title을 우선한다.
- Service line과 Positioning line은 Primary title 바로 아래의 보조 문구로 사용한다.
- 화면별 기능 설명은 세 문구 아래에 배치하며 핵심 브랜드 문구를 대체하지 않는다.
- '비의료적' 표현과 트레이너 최종 검토 원칙을 유지한다.
- 이미지에 포함된 동일 문구를 가리거나 다른 제목으로 덮지 않는다.

## Avoid

- 의료 진단, 치료, 처방 또는 효과를 확정하는 표현
- 제품명을 BodyScan AI, Healthcare Premium 등 과거 명칭으로 대체하는 표현
- 페이지마다 서로 다른 슬로건을 최상위 제목으로 사용하는 방식
