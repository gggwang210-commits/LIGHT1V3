# LIGHT ONE 사업 방향

## 1. 첫 번째 목표

LIGHT ONE의 첫 번째 목표는 트레이너와 회원이 함께 쓰는 **운동·컨디션 기록 기반 대시보드 SaaS**를 만드는 것이다. 이 서비스는 회원의 운동 기록, 컨디션 변화, 체형 변화, 인바디 수치, 생활패턴 기록을 한곳에 모으고, 트레이너가 이를 검토해 회원에게 이해하기 쉬운 피드백과 다음 행동을 제공하도록 돕는다.

LIGHT ONE은 AI가 몸 상태를 진단하거나 운동을 자동 처방하는 서비스가 아니다. 핵심 가치는 **회원의 기록을 설명 가능한 변화 자료로 바꾸고, 트레이너의 코칭과 소통 품질을 높이는 것**이다.

## 2. 한 줄 방향

LIGHT ONE은 PT센터, 헬스장, 필라테스·컨디셔닝 센터가 회원의 운동·컨디션·체형 변화 기록을 구조화하고, 트레이너 검토 기반 피드백과 리포트를 제공하는 비의료 웰니스 대시보드 SaaS다.

## 3. 핵심 사용자

| 사용자 | 해야 할 일 | LIGHT ONE이 제공할 가치 |
|---|---|---|
| 회원 | 내 운동 기록, 컨디션, 체형 변화, 피드백을 확인 | 변화가 눈에 보이고 다음 행동이 명확한 경험 |
| 트레이너 | 회원의 운동 기록과 측정값을 분석하고 피드백 작성 | 상담 준비 시간 단축, 코칭 품질 표준화, 재등록 상담 자료 확보 |
| 센터 관리자 | 회원 관리, 트레이너 업무, 리포트 품질, 운영 지표 확인 | 센터 운영 상태와 리텐션 기회를 조기에 파악 |

## 4. 제품이 다루는 기록

LIGHT ONE의 데이터는 의료 판단이 아니라 운동 상담과 컨디셔닝 코칭을 위한 참고 기록이다.

| 기록 영역 | 예시 | 제품 내 역할 |
|---|---|---|
| 운동 기록 | 운동명, 세트, 반복, 중량, RPE, 수행 메모 | 운동 강도와 수행 흐름 파악 |
| 컨디션 기록 | 피로감, 에너지, 스트레스, 통증 반응, 회복감 | 당일 운동 강도 조절과 트레이너 확인 |
| 생활패턴 기록 | 수면 시간, 수면 질, 활동량, 생활 리듬 | 컨디션 변화 설명과 회복 관리 참고 |
| 스마트워치 연동 후보 | Samsung Health 등에서 가져올 수 있는 수면·활동 데이터 | 초기에는 수동 입력, 이후 연동 검토 |
| 인바디 기록 | 체중, 골격근량, 체지방률 등 | 체성분 변화 설명과 상담 자료 |
| 체형·자세 참고 기록 | 촬영 QC, 자세 변화 참고 지표, 체형 분석 메모 | 트레이너 검토용 변화 비교 자료 |
| 커뮤니케이션 기록 | 트레이너 피드백, 회원 질문, 세션 후 메모 | 피드백 이력과 다음 상담 연결 |

## 5. 회원 대시보드 방향

회원 대시보드는 “내 몸이 어떻게 변하고 있고, 다음에 무엇을 하면 되는지”를 쉽게 보여줘야 한다.

- 내 운동 기록과 세션 이력 확인
- 체형 변화, 인바디 변화, 컨디션 변화 요약
- 수면·생활패턴 입력 또는 스마트워치 연동 후보 데이터 확인
- 트레이너가 검토한 피드백과 다음 과제 확인
- 통증 반응이나 불편감을 트레이너에게 전달
- 상담 리포트와 변화 히스토리 열람

회원 화면은 복잡한 지표보다 쉬운 언어와 다음 행동을 우선한다. 의학적 판단처럼 보이는 문장 대신 “기록”, “참고”, “트레이너 확인”, “컨디셔닝 제안”을 사용한다.

## 6. 트레이너 대시보드 방향

트레이너 대시보드는 회원별 운동 기록, 컨디션 기록, 인바디 수치, 체형·자세 참고 기록을 분석해 더 나은 상담과 피드백을 준비하도록 도와야 한다.

- 회원별 운동 수행, RPE, 통증 반응, 컨디션 흐름 확인
- 인바디와 체형 변화 자료를 한 화면에서 비교
- 스마트워치·생활패턴 기록을 운동 강도 조절 참고 자료로 활용
- REVIEW/BLOCK 등 확인이 필요한 세션을 우선순위화
- 회원에게 보낼 피드백 초안과 상담 리포트 작성 보조
- 다음 세션의 운동 강도, 동작 범위, 회복 과제, 주의사항 제안
- 재등록 상담에 사용할 변화 요약과 설명 포인트 정리

트레이너 화면은 “분석 결과를 대신 판단”하는 구조가 아니라, 트레이너가 더 빠르고 일관되게 판단하도록 돕는 구조여야 한다.

## 7. 솔루션 제공 방식

LIGHT ONE이 제공하는 솔루션은 자동 처방이 아니라 트레이너 검토를 전제로 한 코칭 보조다.

| 상황 | 시스템이 돕는 일 | 최종 책임 |
|---|---|---|
| 수면 부족과 높은 피로감 | 운동 강도 조절 참고 신호 표시 | 트레이너 검토 |
| 통증 반응 증가 | REVIEW/BLOCK 큐로 우선 확인 요청 | 트레이너 확인 및 필요 시 전문가 상담 안내 |
| 인바디 변화 정체 | 운동·생활패턴 기록과 함께 상담 포인트 제안 | 트레이너 피드백 |
| 체형·자세 참고 지표 변화 | 촬영 QC와 변화 비교 자료 제공 | 트레이너 설명 |
| 회원 질문 발생 | 이전 기록과 피드백 이력을 함께 표시 | 트레이너 답변 |

## 8. MVP 우선순위

1. 회원·트레이너 계정과 역할별 대시보드
2. 운동 기록, RPE, 통증 반응, 컨디션 기록 입력
3. 트레이너 피드백과 회원 요청/답변 흐름
4. 인바디 수치와 체형·자세 참고 기록의 수동 입력 및 변화 비교
5. QS/JATC와 AUTO/REVIEW/BLOCK 기반 검토 우선순위
6. 회원용 변화 리포트와 트레이너 검토용 리포트 초안
7. 수면·생활패턴 수동 입력
8. Samsung Health 등 스마트워치 연동은 파일럿 이후 검토

## 9. 비의료 경계

LIGHT ONE은 다음을 하지 않는다.

- 질병 진단
- 치료 효과 판정
- 통증 원인 확정
- 자동 운동 처방 확정
- 의료기관 제출용 진단 리포트 생성
- 스마트워치·인바디 데이터를 통한 질병 위험 예측

대신 다음 표현을 사용한다.

- 컨디션 기록
- 통증 반응 기록
- 운동 강도 조절 참고
- 트레이너 검토 필요
- 비의료 웰니스 참고 리포트
- 다음 세션 컨디셔닝 제안

## 10. 사업 방향 요약

LIGHT ONE은 단순 자세 분석 앱도, 일반 운동기록 앱도 아니다. 첫 번째 사업 방향은 **트레이너와 회원 사이의 기록, 분석, 피드백, 리포트, 소통을 하나로 묶는 컨디셔닝 대시보드 SaaS**다.

이 방향이 분명해지면 제품 개발의 우선순위도 명확해진다. 먼저 현장에서 바로 쓰이는 기록과 피드백 흐름을 만들고, 이후 스마트워치 연동, 인바디·체형 분석 고도화, 센터 운영 지표, 교육·인증 모델로 확장한다.
