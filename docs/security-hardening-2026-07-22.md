# 채용 열람 기준 보안 개선 기록 — 2026-07-22

대상은 공개 저장소의 기본 브랜치 `Main-ONE`을 기준으로 생성한 별도 보안 브랜치입니다. 이 기록은 코드 수준 검증 결과이며 운영 인증이나 법률 적합성 보증이 아닙니다.

## 확인된 위험과 조치

| 위험 | 영향 | 보안 브랜치 조치 |
|---|---|---|
| `DEBUG`가 기본 활성화 | 오류 화면과 내부정보 노출 가능 | 기본값 `False`, 로컬 설정도 명시적 활성화 필요 |
| `SECRET_KEY` 대체 문자열 | 서명값 위조 위험 | 환경변수 미설정 시 즉시 실패 |
| 고정 데모 인증정보 | 자동화 공격과 보안 인식 감점 | 환경변수 또는 실행 시 무작위 생성 |
| 사람 이름 형태의 합성 데이터 | 실제 개인정보로 오인 가능 | `SYN-*`, `데모회원-*` 식별자로 교체 |
| 추적된 SQLite DB | 출처·동의 불명 기록과 건강 인접 정보 노출 위험 | 저장소 추적 대상에서 제거, 마이그레이션·합성 시드로 재생성 |

## 실행 영향

- 환경변수 없이 Django를 시작하면 의도적으로 실패합니다.
- 로컬 데모는 `.env.example`을 복사한 뒤 `SECRET_KEY`, `DEBUG=True`, `DJANGO_SETTINGS_MODULE=mysite.settings_local`을 명시해야 합니다.
- 시드 명령은 `DEBUG=False`에서 거부됩니다.
- 운영 구성은 PostgreSQL과 별도 운영 의존성을 요구합니다.

## 검증 범위

- Django system check와 기존 테스트
- 시드의 운영 모드 차단 및 무작위 비밀번호 테스트
- 공개 저장소의 고정 인증정보와 추적 DB 회귀 테스트
- 비밀정보·식별정보·비의료 경계 문자열 재검색

최종 테스트 수와 결과는 브랜치 커밋 및 PR 설명에 기록합니다.
