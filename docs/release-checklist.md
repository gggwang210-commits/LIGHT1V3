# LIGHT ONE V3 출시 준비 체크리스트

이 체크리스트는 로컬 MVP를 운영 서비스로 오인하지 않도록 출시 판단 기준을 분리합니다. 현재 상태는 로컬 파일럿 MVP이며, 아래 운영 게이트는 완료로 간주하지 않습니다.

## 저장소 게이트

- [ ] 기본 브랜치 기준 CI가 모두 통과한다.
- [ ] 마이그레이션 누락이 없다.
- [ ] 추적 DB, `.env`, 키, 토큰, 비밀번호, 원본 고객 미디어가 없다.
- [ ] 의존성 취약점과 라이선스를 검토했다.
- [ ] 코드·이미지·폰트·영상의 배포 권리를 확인했다.

## 애플리케이션 보안 게이트

- [ ] 운영 비밀관리자와 키 순환 절차가 있다.
- [ ] 역할·객체 단위 접근권한과 관리자 권한을 검증했다.
- [ ] HTTPS, 보안 쿠키, HSTS, 허용 호스트를 실제 배포 환경에서 검증했다.
- [ ] 감사 로그, 오류 모니터링, 백업·복구와 침해 대응 절차가 있다.
- [ ] 파일 업로드를 사용한다면 형식·크기·악성 콘텐츠·접근권한을 검증했다.

## 개인정보 게이트

- [ ] 처리 목적, 최소 수집 항목, 동의, 보유기간과 파기 기준이 확정됐다.
- [ ] 열람·정정·삭제 요청 처리 절차가 있다.
- [ ] 민감정보 해당 여부와 위탁·국외 이전 여부를 법률 전문가와 검토했다.
- [ ] 실제 데이터 없이도 개발·테스트가 가능한 합성 데이터 절차가 있다.
- [ ] 테스트, 로그, 백업과 분석 도구에 개인정보가 유출되지 않는지 검증했다.

## 비의료·제품 게이트

- [ ] 진단, 치료, 처방, 재활 판정 또는 질병 위험 예측으로 오인될 문구가 없다.
- [ ] QS/JATC와 라우팅 임계값의 근거와 한계를 사용자에게 설명한다.
- [ ] 트레이너 검토와 이의 제기·수정 흐름이 실제 화면에서 동작한다.
- [ ] 파일럿 지표와 사용자 주장은 재현 가능한 근거가 있다.

## 출시 판단

| 판단 | 기준 |
|---|---|
| 로컬 데모 가능 | 합성 데이터, 로컬 설정, 기본 테스트 통과 |
| 제한된 파일럿 검토 가능 | 참여자 동의, 최소 수집, 접근 통제, 중단 기준을 별도 승인 |
| 운영 배포 가능 | 위 모든 게이트와 조직별 보안·법률 검토 완료 |

체크되지 않은 항목은 미검증입니다. 일부 코드 검사 통과만으로 운영 준비 완료를 선언하지 않습니다.
