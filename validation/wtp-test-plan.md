# WTP 검증 계획

본 자료는 비의료 운동상담 참고용이며, 의료 진단·치료·처방 목적이 아닙니다. 모든 판단은 담당 트레이너가 검토합니다.

WTP는 Willingness To Pay, 즉 고객 지불의사를 뜻합니다. LIGHT ONE V2는 기능 완성보다 먼저 실제 센터가 비용을 낼 이유를 검증해야 합니다.

## 1. 검증 가설

- 트레이너는 상담 준비 시간을 줄이면 리포트 SaaS를 사용할 가능성이 있다.
- 센터 대표는 재등록 상담 품질이 올라가면 월 구독을 검토할 가능성이 있다.
- 단순 점수화보다 설명 가능한 리포트가 더 높은 지불의사를 만든다.

## 2. 가격 실험안

- 무료 파일럿 2주
- 월 49,000원 테스트
- 월 99,000원 테스트
- 센터당 트레이너 계정 추가 과금 검토
- 리포트 건당 과금은 보조안으로만 검토

## 3. 질문 방식

가격을 바로 묻기보다 현재 비용과 대안을 먼저 확인합니다.

- 지금 상담 기록 정리에 드는 시간 비용은 어느 정도인가요?
- 현재 쓰는 대안은 무엇인가요?
- 이 리포트가 실제 재등록 상담에 쓰인다면 월 얼마까지 검토할 수 있나요?
- 결제 전에 반드시 필요한 기능은 무엇인가요?

## 4. 통과 기준

- 파일럿 센터 1곳 이상이 유료 전환 조건을 구체적으로 제시
- 트레이너 2명 이상이 반복 사용 의사 표현
- 센터 대표가 월 비용 또는 리포트당 비용 중 하나를 선택
- 의료 오인 리스크가 낮다는 피드백 확보
