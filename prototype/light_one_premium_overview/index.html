REVIEW PRIORITY

상태는 진단이 아니라,
다음 확인의 순서입니다.

카드를 열어 운영상 의미와 회원 공개 원칙을 확인하세요.

AUTO

기본 검토 절차

일반적인 트레이너 확인 흐름으로 진행 가능한 상태입니다.

다음 행동: 트레이너가 기록과 초안을 확인합니다.
회원 공개: 검토·승인 전 자동 공개하지 않습니다.
REVIEW

추가 확인 필요

입력, QC 또는 불편 반응 기록을 추가로 확인하는 상태입니다.

다음 행동: 동작 범위, 피로도, 휴식, 기록 누락과 안내 문구를 검토합니다.
회원 공개: 담당 트레이너 확인 후에만 안내합니다.
BLOCK

진행 보류·확인 대기

트레이너 확인 전 리포트 또는 자동 안내를 보류하는 상태입니다.

다음 행동: 담당 트레이너가 원본 기록과 적절한 안내 방식을 확인합니다.
회원 공개: 승인 전에는 자동 전달하지 않습니다.
안내: AUTO / REVIEW / BLOCK은 의료 위험도나 진단 결과가 아닌, 트레이너 검토를 위한 운영 우선순위입니다.
PILOT VALIDATION

기능 확장보다 먼저,
반복 사용의 증거를 만듭니다.

성과를 주장하기 전, 실제 현장에서 어떤 문제를 줄이고 어떤 흐름이 반복 사용되는지 검증합니다.

PILOT HYPOTHESIS

작게 시작하고,
운영 증거를 남깁니다.

센터의 실제 상담 장면에서 “기록 → 검토 → 설명 → 다음 행동” 흐름이 반복 사용되는지를 확인하는 단계입니다.

2–3파일럿 센터
6–8주검증 기간
1–3명센터당 트레이너

체크는 데모 인터랙션이며, 검증 완료 또는 성과 달성을 의미하지 않습니다.

LIGHT ONE V3 · Non-medical Pilot MVP

LIGHT ONE은 의료 진단·치료·처방·재활 판정 또는 질병 예측을 제공하지 않습니다. 본 페이지의 정보와 화면은 합성 데이터 기반의 비의료 운동상담 참고용 데모이며, 모든 결과는 담당 트레이너 검토를 전제로 합니다. 실제 데이터는 권한, 동의, 삭제, 보안 체계가 검증되기 전까지 사용하지 않습니다.
