WHY LIGHT ONE

상담 품질은 개인의 기억이 아니라,
운영 구조에서 시작됩니다.

LIGHT ONE은 기록을 더 많이 남기는 도구가 아닙니다. 상담 전 필요한 맥락을 같은 흐름 안에서 확인하도록 돕는 Pilot MVP입니다.

기록이 흩어집니다

운동·컨디션·상담 메모가 메신저, 노트, 문서에 나뉘면 다음 상담의 맥락이 끊깁니다.

준비가 반복됩니다

세션 직전 과거 기록을 찾고 정리하는 부담이 누적되면 중요한 대화에 쓸 시간이 줄어듭니다.

설명이 흔들립니다

트레이너별 기록과 변화 설명 방식이 달라지면 회원이 다음 행동을 이해하는 경험도 달라집니다.

HUMAN-IN-THE-LOOP

시스템은 초안을 만들고,
트레이너가 최종 확인합니다.

모든 흐름은 회원 전달보다 트레이너의 검토를 먼저 둡니다. 판단을 대체하는 점수가 아니라, 더 나은 상담 준비를 위한 운영 설계입니다.

REVIEW PRIORITY

상태는 진단이 아니라,
다음 확인의 순서입니다.

카드를 열어 각 상태의 운영상 의미, 트레이너의 다음 행동, 회원 공개 원칙을 확인하세요.

AUTO

기본 검토 절차

일반적인 트레이너 확인 흐름으로 진행 가능한 상태입니다.

다음 행동: 트레이너가 기록과 초안을 확인합니다.
회원 공개: 검토·승인 전 자동 공개하지 않습니다.
REVIEW

추가 확인 필요

입력, QC 또는 불편 반응 기록을 추가로 확인하는 상태입니다.

다음 행동: 기록 누락, 피로도, 휴식, 안내 문구를 검토합니다.
회원 공개: 담당 트레이너 확인 후에만 안내합니다.
BLOCK

진행 보류·확인 대기

트레이너 확인 전 리포트 또는 자동 안내를 보류하는 상태입니다.

다음 행동: 담당 트레이너가 원본 기록과 적절한 안내 방식을 확인합니다.
회원 공개: 승인 전에는 자동 전달하지 않습니다.

안내: AUTO / REVIEW / BLOCK은 의료 위험도나 진단 결과가 아닌, 트레이너 검토를 위한 운영 우선순위입니다.
