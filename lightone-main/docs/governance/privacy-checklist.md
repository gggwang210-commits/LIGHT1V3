# Privacy Checklist

Use this checklist before collecting or processing any member information.

- [ ] Confirm the specific purpose of collection.
- [ ] Collect the minimum fields required for PT consultation report drafting.
- [ ] Obtain documented consent before collecting images, videos, body-related data, or self-reported discomfort information.
- [ ] Avoid storing raw images or videos unless retention is necessary and consented.
- [ ] Separate member identifiers from report inputs where practical.
- [ ] Restrict access by role and keep an audit trail for exported reports.
- [ ] Define retention and deletion periods before pilot operation.
