# Pilot Execution Checklist

이 체크리스트는 LIGHT ONE 파일럿을 실행하기 위한 운영 문서다. 기준 문서는 [`docs/validation/pilot-validation-plan.md`](validation/pilot-validation-plan.md)이며, 고객 인터뷰는 [`docs/customer-validation-interview-guide.md`](customer-validation-interview-guide.md), 참여 의향 확인은 [`docs/pilot-loi-template.md`](pilot-loi-template.md)를 사용한다.

## 1. 파일럿 목적

- 트레이너가 상담·세션 데이터를 일관되게 입력할 수 있는지 확인한다.
- 회원과 트레이너가 비의료 상담 리포트를 이해하고 실제 상담에 활용할 수 있는지 확인한다.
- QS/JATC, 가격, 재등록 상담 리포트 수요, 개인정보·안전 경계 리스크를 검증 전 가정에서 실제 근거로 전환할 수 있는지 확인한다.

## 2. 참여 조건

| 항목 | 최소 조건 |
|---|---|
| 센터 | PT샵, 헬스장 PT 조직, 필라테스·운동지도 센터 중 1곳 이상 |
| 담당자 | 원장 또는 운영 책임자 1명, 현장 트레이너 1명 이상 |
| 기간 | 4~8주 권장 |
| 회원 | 동의 가능한 파일럿 회원 5명 이상부터 시작 |
| 세션 | 회원당 4회 이상 기록 권장 |
| 교육 | 시작 전 30~60분 온보딩, 중간 점검 1회 |
| 동의 | 데이터 수집·익명화·비의료 목적 고지에 동의한 참여자만 포함 |
| 제외 | 의료 진단·치료·재활 처방 목적 참여, 민감 의료정보 제공 요구, 동의 없는 촬영 |

## 3. 데이터 수집 범위

### 3.1 수집 가능 데이터

- 센터 및 운영 데이터: 센터 유형, 트레이너 수, 파일럿 담당자 역할, 세션 운영 방식.
- 회원 기본 상담 데이터: 연령대, 성별 선택값, 운동 목표, 운동 경험, 상담 메모.
- 세션 데이터: 날짜, 운동명, 세트, 반복, 중량 또는 강도, RPE, 휴식, 트레이너 메모.
- 회원 반응 데이터: 불편감 NRS, 피로감, 주관적 만족도, 리포트 이해도.
- 촬영·품질 데이터: 촬영 여부, 촬영 각도, 조명, 전신 포함 여부, Retake 사유.
- 리포트 사용 데이터: 리포트 생성 여부, 트레이너 수정 여부, 상담 사용 여부, 회원 반응.
- 사업성 데이터: 가격 수용도, 유료 전환 조건, 재등록 상담 리포트 필요도, LOI 의향.

### 3.2 수집 금지 또는 별도 검토 데이터

- 진단명, 치료 기록, 병원 검사 결과, 처방 내역 등 의료정보.
- 주민등록번호, 결제카드 전체 번호, 계좌번호 등 불필요한 고유식별·금융정보.
- 동의 없는 얼굴 영상·사진, 제3자가 식별되는 영상·사진.
- 미성년자 데이터는 보호자 동의와 별도 운영 기준 없이는 수집하지 않는다.

## 4. 비의료 면책 문구

파일럿 안내문, 리포트, 인터뷰 스크립트에는 다음 문구를 포함한다.

> LIGHT ONE은 의료 진단, 치료, 재활 처방, 질병 예측, 통증 개선 보장을 제공하지 않습니다. 본 파일럿의 리포트와 QS/JATC 지표는 트레이너가 회원의 운동상담 기록을 정리하고 설명하는 데 활용하는 비의료 참고자료입니다. 통증, 부상, 질병 의심 증상이 있는 경우 의료 전문가의 판단을 우선해야 합니다.

## 5. QS/JATC 검증 전 가정 표시

- QS/JATC 점수, 가중치, AUTO/REVIEW/BLOCK 임계값은 파일럿 전에는 검증된 성능 기준이 아니라 운영 가설이다.
- 모든 문서와 리포트에는 `데모 기준/초기 가정 [확인필요]` 또는 `파일럿 검증 전 가정` 표시를 유지한다.
- 파일럿 결과는 통계적 확증이 아니라 실행가능성, 입력 일관성, 리포트 이해도, 위험 표현 탐지를 위한 근거로 해석한다.
- QS/JATC가 높거나 낮다는 이유만으로 운동 처방, 치료 판단, 의학적 조치를 자동 결정하지 않는다.

## 6. 실행 단계별 체크리스트

### 6.1 시작 전

- [ ] 원장 또는 운영 책임자와 파일럿 목적·범위 합의.
- [ ] [`docs/pilot-loi-template.md`](pilot-loi-template.md) 기반 LOI 또는 참여 확인서 확보.
- [ ] 수집 데이터 범위와 비수집 데이터를 설명하고 동의 절차 확인.
- [ ] 트레이너 온보딩: 입력 항목, 촬영 기준, 비의료 표현, 리포트 검토 절차 안내.
- [ ] QS/JATC와 가격 가정이 검증 전임을 참여자에게 고지.
- [ ] 인터뷰 일정과 중간 점검 일정을 확정.

### 6.2 운영 중

- [ ] 세션별 필수 입력 누락률 확인.
- [ ] 촬영 실패, Retake, 조명·각도 문제를 기록.
- [ ] 리포트 초안에서 의료 오해 표현, 과장 표현, 위험 표현을 표시.
- [ ] 트레이너 수정 소요 시간과 수정 유형을 기록.
- [ ] 회원이 이해하지 못한 항목과 상담에 도움이 된 항목을 기록.
- [ ] 개인정보·동의·촬영 관련 이슈를 즉시 로그로 남김.

### 6.3 종료 후

- [ ] 원장 인터뷰: 유료 전환 조건, 가격 수용도, 운영 부담, 재등록 상담 수요 확인.
- [ ] 트레이너 인터뷰: 입력 지속 가능성, 리포트 품질, 상담 사용성 확인.
- [ ] 회원 피드백: 리포트 이해도, 부담감, 신뢰감, 개인정보 우려 확인.
- [ ] QS/JATC 입력 가능성, 결측률, 오해 가능성, 임계값 조정 필요성을 정리.
- [ ] LOI 후속 단계 또는 유료 PoC 전환 여부 확인.
- [ ] 검증되지 않은 수치와 과장 문구를 제품·IR 문서에서 제거 또는 `[확인필요]` 처리.

## 7. 성공 판단 기준

| 영역 | 판단 질문 |
|---|---|
| 사용성 | 트레이너가 세션 흐름을 크게 방해받지 않고 입력할 수 있는가? |
| 리포트 가치 | 원장·트레이너·회원이 재등록 상담 또는 변화 설명에 쓸 수 있다고 보는가? |
| 가격 | 최소 1개 이상 가격대에서 유료 전환 검토 의향이 있는가? |
| 안전 | 의료 오해 표현과 개인정보 리스크가 통제 가능한가? |
| 데이터 | QS/JATC 산출에 필요한 핵심 데이터가 결측 없이 수집되는가? |
| 후속 전환 | LOI, 유료 PoC, 추가 파일럿 중 하나로 이어질 가능성이 있는가? |
