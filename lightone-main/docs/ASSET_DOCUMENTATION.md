## 2. 카테고리별 상세 분석

### 2.1 사업자용 대시보드 (H_ 시리즈, 5개 파일)

**대상 사용자:** PT 센터 오너, 매니저, 사업자

#### H_dashboard1.png — 고객 신체 측정 요약 (v1)

- 개별 고객의 체형 분석 결과를 한 눈에 보여주는 대시보드
- 상단에 고객 기본 정보(이름, 성별, 나이, 키, 체중), 측정 날짜 표시
- 좌측에 전신 포즈 추정 시각화(정면·측면), 주요 관절각도·좌우 균형 수치 배치
- 우측에 주요 지표 카드: 어깨 기울기, 골반 기울기, 무릎 정렬 등 수치화
- 하단에 이전 측정과의 변화 추이 그래프(시계열)
- 색상 체계: 네이비/블루 기반, LIGHT ONE 브랜드 컬러 반영

#### H_dashboard_2v.png — 고객 신체 측정 요약 (v2)

- v1의 레이아웃을 개선한 반복 버전
- 시각적 위계(hierarchy) 조정: 핵심 지표 카드의 크기·배치 변경
- 포즈 시각화 영역과 수치 영역 간 구분선·여백 개선
- 차트 스타일 미세 조정

#### H_dashbord2.png — 체형 분석 상세 리포트

- 전신 포즈 추정 결과의 상세 분석 화면
- 관절 각도별 정상 범위와 현재 값을 비교하는 바(bar) 차트 또는 게이지
- 체형 유형 분류 결과 표시(라운드숄더, 거북목, 골반 전방경사 등)
- 트레이너 코멘트/메모 입력 영역 포함
- 운동 추천(corrective exercise) 영역 하단 배치

#### H_dashborad3.png — 다중 고객 관리·비교

- 센터 내 전체 고객 리스트 및 필터링 기능
- 고객별 최근 측정일, 개선 진행률 등을 카드 또는 테이블로 표시
- 고객 간 체형 지표 비교 기능 시각화
- 센터 전체 통계(평균 개선율, 활성 고객 수 등) 요약 카드

#### H_dashborad_4.png — 센터 관리 통합 대시보드

- 센터 운영 관점의 통합 뷰
- 매출·예약·고객 수 등 비즈니스 KPI 영역
- 트레이너별 담당 고객 수, 활동 현황
- 장비·공간 활용률 또는 일정 관리 블록
- 가장 넓은 스코프의 대시보드로, 사업자(오너) 의사결정 지원 목적

## 3. 디자인 시스템 관찰

### 3.1 컬러 팔레트

| 용도 | 색상 | 비고 |
|------|------|------|
| Primary | 네이비 (#1B2A4A 계열) | 헤더, 사이드바, 주요 타이틀 |
| Accent | 블루 (#3B82F6 계열) | 활성 지표, 버튼, 하이라이트 |
| Background | 화이트/라이트그레이 | 카드 배경, 콘텐츠 영역 |
| Alert/Warning | 레드/오렌지 계열 | 비정상 범위 수치 강조 |
| Positive | 그린 계열 | 정상 범위, 개선 표시 |

### 3.2 레이아웃 패턴

- **좌측 사이드바 내비게이션 + 메인 콘텐츠 영역** 구조 반복
- **상단 요약 카드 → 중단 시각화 → 하단 상세 테이블** 3단 위계
- 카드(Card) 컴포넌트 기반 모듈러 설계
- 반응형(responsive) 고려 여부는 이미지만으로는 판단 불가

### 3.3 타이포그래피

- 한글 본문: Noto Sans KR 또는 유사 고딕 계열 추정
- 영문/숫자: Inter 또는 유사 산세리프 추정
- 수치 강조에 볼드·대형 폰트 사이즈 적용

## 4. 검증 결과 및 개선 권장사항

### 4.1 강점

- **사용자 역할 분리 명확:** 사업자(H_)와 트레이너(T_) 대시보드가 대상 사용자별로 분리되어 있어 B2B SaaS 구조에 적합
- **시각적 일관성:** 네이비/블루 브랜드 컬러가 전 화면에 걸쳐 일관 적용
- **정보 위계:** 요약 → 상세 흐름이 대시보드 설계 모범 사례(best practice)에 부합
- **비의료 웰니스 포지셔닝 유지:** 의료 진단 용어 대신 체형·자세·균형 등 웰니스 언어 사용 확인

### 4.2 개선 권장사항

| 항목 | 현황 | 권장 조치 | 우선순위 |
|------|------|-----------|----------|
| **파일명 컨벤션** | 오타 혼재 (`dashbord`, `dashborad`, `dashboard`) | 통일된 네이밍 규칙 적용 (예: `H_dashboard_v1.png`) | 높음 |
| **버전 관리** | `_2v`, `_v1` 등 비일관적 버전 표기 | `_v1`, `_v2`, `_v3` 형식 통일 | 높음 |
| **해상도·크기** | 1.2~1.9 MB 범위, 개별 파일 크기 상이 | 통일된 해상도(예: 1920×1080 또는 2x Retina) 및 압축 기준 설정 | 중간 |
| **접근성(a11y)** | 색상 대비 검증 미확인 | WCAG 2.1 AA 기준 색상 대비 비율 검증 필요 | 중간 |
| **인터랙션 명세** | 정적 이미지만 존재 | 클릭·호버·전환 동작을 기술하는 인터랙션 스펙 문서 추가 권장 | 낮음 |
| **다크모드** | 라이트 모드 단일 | 다크모드 변형 디자인 추가 검토 | 낮음 |

### 4.3 비의료 포지셔닝 검증

전 화면에서 의료 진단·처방 표현은 발견되지 않았다. "체형 분석", "자세 균형", "교정 운동 추천" 등의 웰니스 언어가 사용되어 MFDS 비의료기기 포지셔닝 기조와 부합한다. 다만 향후 기능 확장 시 "진단", "치료", "질환" 등의 의료 용어가 UI에 유입되지 않도록 용어 가이드라인 문서화가 필요하다.
