# Modu Startup Summary

LIGHT ONE is a non-medical PT consultation report SaaS for PT centers, gyms, and Pilates studios. It helps trainers structure member consultation records, exercise-session notes, self-reported discomfort responses, and change summaries into trainer-reviewed reports.

## Current scope

- Rule-based and documentation-first MVP planning
- Static landing page and technical evidence archive
- Camera, lighting, and center-QC modules as optional input-quality support

## Safety position

LIGHT ONE does not provide medical diagnosis, treatment decisions, rehabilitation prescriptions, or disease-risk prediction. Any market, performance, QS, or JATC number that is not backed by completed validation remains `[확인필요]`.
