# Customer Validation Interview Guide

LIGHT ONE 고객검증 인터뷰는 PT샵 원장과 트레이너가 실제로 겪는 상담·기록·재등록 문제, 비의료 리포트 수요, 가격 수용도를 확인하기 위한 실행 문서다. 기준 문서는 [`docs/validation/pilot-validation-plan.md`](validation/pilot-validation-plan.md)이며, 본 문서는 파일럿 전후 인터뷰에 사용한다.

## 1. 진행 원칙

- 대상: PT샵 원장 5명 이상, 현장 트레이너 5명 이상을 우선 목표로 한다.
- 방식: 30~45분 반구조화 인터뷰로 진행하고, 가능하면 실제 상담 기록 양식 또는 리포트 샘플 반응을 함께 확인한다.
- 기록: 응답자명, 센터명, 연락처 등 직접 식별 정보는 별도 동의 없이 본문에 남기지 않는다.
- 금지: 의료 진단, 치료 효과, 통증 개선 보장, 재활 처방 성과를 암시하는 질문이나 설명을 하지 않는다.
- 검증 상태: QS/JATC 점수, 임계값, 가격, 재등록률 개선 기대치는 모두 검증 전 가정이며 `[확인필요]`로 취급한다.

## 2. 공통 오프닝 스크립트

> LIGHT ONE은 의료 진단·치료·처방 서비스가 아니라, PT 현장의 운동상담 기록과 회원 변화 설명을 돕는 비의료 상담 리포트 도구입니다. 오늘 인터뷰는 실제 구매·사용 가능성을 확인하기 위한 고객검증이며, QS/JATC 수치와 가격 가정은 아직 검증 전입니다. 답변은 제품 개선과 파일럿 설계에만 활용하고, 외부 공유 시 개인과 센터를 식별할 수 없도록 익명화하겠습니다.

## 3. PT샵 원장 인터뷰 질문지

### 3.1 현재 운영 문제

1. 회원 상담 기록은 현재 어떤 도구로 관리하나요? 예: 종이, 엑셀, CRM, 카카오톡, 트레이너 개인 메모.
2. 신규 상담, 중간 점검, 재등록 상담 중 가장 시간이 많이 걸리는 단계는 무엇인가요?
3. 회원 변화 근거를 설명할 때 가장 자주 사용하는 자료는 무엇인가요?
4. 트레이너별 상담 품질을 원장 관점에서 확인하거나 관리하는 방식이 있나요?
5. 재등록 실패 시 가장 흔한 이유는 무엇이라고 보나요?

### 3.2 재등록 상담 리포트 수요

1. 재등록 상담 전에 자동으로 정리된 회원 변화 리포트가 있다면 어떤 항목이 꼭 필요할까요?
2. 회원에게 보여줄 리포트와 원장이 내부 관리용으로 보는 리포트는 어떻게 달라야 하나요?
3. 리포트가 재등록 상담에 도움이 되려면 어느 정도의 신뢰도·설명력이 필요하다고 보나요?
4. 샘플 리포트에서 바로 쓰기 어려운 표현, 위험한 표현, 불필요한 항목은 무엇인가요?
5. 재등록 상담 성과를 판단할 때 어떤 지표를 추적하면 좋을까요? 예: 상담 전환율, 재등록률, 객단가, 상담 시간.

### 3.3 파일럿 참여 조건

1. 4~8주 파일럿에 참여한다면 몇 명의 회원과 몇 명의 트레이너가 현실적인가요?
2. 파일럿에 필요한 최소 조건은 무엇인가요? 예: 설치 시간, 교육 시간, 개인정보 동의서, 촬영 공간, 담당자 지정.
3. 센터가 제공할 수 있는 데이터 범위와 제공하기 어려운 데이터는 무엇인가요?
4. 파일럿 종료 후 유료 전환을 검토하려면 어떤 결과가 필요할까요?
5. LOI 또는 파일럿 참여 확인서에 포함되어야 할 조건은 무엇인가요?

### 3.4 가격 수용도

1. 현재 회원관리·상담·리포트 도구에 매월 지출하는 비용은 어느 정도인가요?
2. LIGHT ONE이 재등록 상담 준비 시간을 줄이고 상담 자료를 자동 정리한다면 월 구독료를 검토할 수 있나요?
3. 월 29,000원, 99,000원, 149,000원 중 부담 없이 검토 가능한 범위는 어디인가요? 각 가격대에서 기대하는 기능은 무엇인가요?
4. 센터 단위 과금, 트레이너 계정 단위 과금, 회원 수 기반 과금 중 어떤 방식이 가장 자연스러운가요?
5. 유료 전환 전 반드시 확인해야 하는 조건은 무엇인가요?

## 4. 트레이너 인터뷰 질문지

### 4.1 현장 워크플로우

1. 세션 전·중·후에 회원 상태와 운동 기록을 어떻게 남기나요?
2. 기록을 남기지 못하는 가장 큰 이유는 무엇인가요? 예: 시간 부족, 입력 번거로움, 표준 양식 부재.
3. 회원에게 변화 과정을 설명할 때 어려운 점은 무엇인가요?
4. 통증, 피로, RPE, 운동 수행 품질 같은 정보를 현재 어떻게 확인하나요?
5. 리포트 초안이 자동 생성된다면 트레이너 검토에 몇 분까지 사용할 수 있나요?

### 4.2 QS/JATC 수용성

1. QS/JATC 같은 요약 점수가 현장 상담에 도움이 될 것 같나요? 도움이 된다면 어떤 상황에서인가요?
2. 점수보다 더 중요한 설명 문구나 시각화가 있다면 무엇인가요?
3. QS/JATC 임계값은 아직 검증 전 가정입니다. 현장에서 점수 해석이 오해를 만들 가능성은 무엇인가요?
4. AUTO/REVIEW/BLOCK 같은 라우팅이 있다면 트레이너가 최종 판단해야 할 지점은 어디인가요?
5. 회원에게 절대 보여주면 안 되는 표현이나 의료적으로 오해될 수 있는 표현은 무엇인가요?

### 4.3 데이터 입력과 리포트 사용

1. 필수 입력으로 받아들일 수 있는 최소 데이터는 무엇인가요?
2. 사진·영상 촬영이 필요한 경우 회원 거부감이나 공간 제약은 어느 정도인가요?
3. 리포트가 세션 계획, 회원 설명, 재등록 상담 중 어디에 가장 먼저 쓰일까요?
4. 재등록 상담용 리포트에서 가장 설득력 있는 항목은 무엇인가요?
5. 파일럿 기간 동안 지속 사용을 방해할 수 있는 요인은 무엇인가요?

## 5. 인터뷰 결과 정리 템플릿

| 구분 | 기록 항목 |
|---|---|
| 응답자 유형 | 원장 / 트레이너 |
| 센터 규모 | 트레이너 수, 회원 수, PT 세션 수 |
| 핵심 문제 | 상담 기록, 재등록, 리포트, 품질관리 중 주요 pain point |
| 현재 대안 | 사용 중인 CRM, 엑셀, 종이, 수기 프로세스 |
| 리포트 수요 | 반드시 필요한 항목, 불필요한 항목, 위험 표현 |
| 가격 반응 | 수용 가능 범위, 거부 가격, 과금 선호 방식 |
| 파일럿 의향 | 참여 가능 여부, 조건, 예상 장애물 |
| 후속 액션 | LOI 요청, 샘플 리포트 전달, 파일럿 체크리스트 공유 |
