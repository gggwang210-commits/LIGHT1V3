# Pilot LOI Template

본 문서는 LIGHT ONE 파일럿 참여 의향을 확인하기 위한 비구속 LOI 초안이다. 실제 계약서가 아니며, 법률 검토 전에는 구속력 있는 계약으로 사용하지 않는다. 실행 체크리스트는 [`docs/pilot-execution-checklist.md`](pilot-execution-checklist.md)를 따른다.

- 파일럿 담당 트레이너: `[성명 / 역할]`

## 3. 파일럿 목적

참여 센터는 LIGHT ONE이 제공하는 비의료 PT 상담 리포트 도구의 현장 사용성, 데이터 입력 가능성, 재등록 상담 리포트 수요, 가격 수용도, 개인정보·안전 경계 리스크를 검토하기 위해 파일럿 참여 의향을 표시한다.

## 4. 비의료 고지

LIGHT ONE은 의료 진단, 치료, 재활 처방, 질병 예측, 통증 개선 보장을 제공하지 않는다. QS/JATC 지표와 리포트 문구는 트레이너의 운동상담 기록 정리와 회원 설명을 돕는 비의료 참고자료이며, 통증·부상·질병 의심 상황에서는 의료 전문가의 판단을 우선한다.

## 5. QS/JATC 검증 상태

참여 센터는 QS/JATC 점수, 가중치, 임계값, AUTO/REVIEW/BLOCK 라우팅, 가격 가정, 재등록률 개선 기대치가 파일럿 검증 전 가정임을 이해한다. 파일럿 결과는 제품 개선과 후속 검증 설계에 활용되며, 확정 성능이나 의료적 효과를 의미하지 않는다.

## 7. 데이터 수집 및 보호

### 7.1 수집 대상

- 회원 운동 목표, 세션 기록, RPE, 불편감 NRS, 트레이너 메모.
- 리포트 생성·수정·상담 사용 여부.
- 촬영 품질 및 Retake 사유.
- 원장·트레이너의 가격 수용도, 유료 전환 조건, 재등록 상담 리포트 수요.

### 7.2 수집 제외

- 진단명, 치료 기록, 병원 검사 결과, 처방 내역 등 의료정보.
- 주민등록번호 등 불필요한 고유식별정보.
- 동의 없는 사진·영상·음성.

### 7.3 처리 원칙

- 파일럿 참여자에게 수집 목적, 범위, 보관 기간, 익명화 방식, 철회 가능성을 안내한다.
- 외부 공유 자료에는 개인과 센터를 식별할 수 있는 정보를 제거한다.
- 원본 데이터 접근 권한은 파일럿 운영에 필요한 최소 인원으로 제한한다.

## 8. 참여 센터 협조 사항

- 파일럿 담당자와 트레이너를 지정한다.
- 참여 회원에게 파일럿 목적과 비의료 고지를 설명하고 동의를 확인한다.
- 세션 기록과 리포트 피드백을 가능한 범위에서 성실히 제공한다.
- 의료 오해, 개인정보 이슈, 운영 장애가 발생하면 즉시 LIGHT ONE 팀에 알린다.

## 9. LIGHT ONE 팀 제공 사항

- 파일럿 온보딩과 사용 안내.
- 리포트 샘플 또는 MVP 접근 권한.
- 데이터 입력 양식, 인터뷰 질문지, 실행 체크리스트.
- 파일럿 종료 후 요약 리포트 또는 개선안 공유.

## 10. 가격 수용도 및 후속 검토

파일럿 종료 후 참여 센터는 다음 항목에 대해 의견을 제공한다.

- 월 29,000원 / 99,000원 / 149,000원 등 가격대별 수용 가능성.
- 센터 단위, 트레이너 계정 단위, 회원 수 기반 과금 중 선호 방식.
- 유료 전환을 위해 필요한 기능, 리포트 품질, 데이터 보호 조건.
- 재등록 상담 리포트가 실제 상담 시간 단축, 상담 품질관리, 재등록 설득에 도움이 되는지 여부.

## 11. 비구속성

본 LOI는 파일럿 참여 의향과 협의 범위를 확인하기 위한 문서이며, 별도 계약 체결 전까지 구매 의무, 독점권, 성과 보장, 장기 사용 의무를 발생시키지 않는다.
